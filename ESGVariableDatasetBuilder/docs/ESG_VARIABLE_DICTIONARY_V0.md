# ESG Variable Dictionary v0

The final dataset contains 31 company-year variables across environment,
social, governance, controversy, and financial families.

Financial and controversy variables are searched only in PDFs already present in
the corpus and upstream preparation outputs. No external market, controversy,
news, API, or web source is used.

If a variable is not found in the available corpus outputs, its status is
`missing_from_corpus`.

The machine-readable dictionary is
`ESGVariableDatasetBuilder/config/esg_variable_dictionary_v0.yaml`.
