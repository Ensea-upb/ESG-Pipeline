# Release Notes V1.0

ESGVariableDatasetBuilder v1.0 builds the final company x year CSV of ESG,
controversy, and financial variables from corpus-derived preparation outputs.

It adds:

- variable dictionary for 31 final variables;
- input discovery for ESGIndicatorDatabase outputs;
- preparation-only loader;
- indicator-to-variable mapping;
- value selection with explicit statuses;
- main, enriched, long, evidence, lineage, missing, and quality outputs;
- contract validation;
- multi-company-year build command.

It does not produce ESG scores, ESG ratings, or external-source enrichment.
