# ESGTableExtraction v1.0 - Release Notes

First stable candidate-only table extraction engine.

Features:

- table and cell loading;
- matrix reconstruction;
- header/year/unit structure detection;
- ESG row classification;
- table metric candidate extraction;
- table quality audit;
- typed CSV exports;
- contract validation;
- multi-document audit.

No score or validated ESG indicator is produced.
