# User Guide - Business UI v1.1

## Parcours recommandé

1. Ouvrir `streamlit run ESGProductionControlCenter/app.py`.
2. Aller dans `Poste de controle`.
3. Choisir une entreprise.
4. Choisir une année.
5. Choisir un document.
6. Lancer d'abord une simulation.
7. Lire les résultats et les blocages.
8. Faire la revue humaine si nécessaire.
9. Télécharger les CSV utiles.

## Revue humaine

Utiliser `Accepter pour préparation`, `Rejeter`, `Demander plus de preuves` ou
`Reporter la décision`. Une acceptation n'est pas un indicateur final validé.

## Base préparatoire

La base reste `preparation_only`. Elle ne produit aucun score ESG et aucun
indicateur final validé.
