# Release Notes - ESGProductionControlCenter v1.1

v1.1 transforme l'interface technique en interface métier.

Ajouts principaux :

- vocabulaire métier pour les étapes;
- sélection entreprise / année / document;
- suivi visuel de progression;
- résultats lisibles sans jargon technique;
- revue humaine simplifiée;
- base préparatoire affichée clairement;
- rapport métier de run;
- détails techniques disponibles mais secondaires.

La release ne change aucune logique métier et ne modifie aucun module existant.
