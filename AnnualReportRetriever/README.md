# AnnualReportRetriever

## Objectif

`AnnualReportRetriever` est un moteur Python spécialisé dont l’objectif est de télécharger automatiquement le rapport annuel d’une entreprise pour une année donnée.

Le problème traité est le suivant :

```text
Entreprise A + année X
        ↓
recherche automatique de candidats
        ↓
classification et scoring des candidats
        ↓
sélection du meilleur rapport annuel
        ↓
téléchargement du PDF
        ↓
stockage local structuré
        ↓
création d’un manifest JSON
