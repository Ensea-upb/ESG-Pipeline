# ESGManualReview v1.0 - Release Notes

This release introduces a controlled human-in-the-loop review layer.

It can:

- load `ESGIndicatorValidation` outputs;
- build a readable review workspace;
- generate an empty decision template;
- apply explicit human decisions;
- audit missing/invalid decisions;
- validate outputs with a contract.

It does not produce final ESG indicators or scores.
