# Review Guide v1.0

Allowed decisions:

- `accept_candidate`: keep this candidate for a future preparation database. This is not a final ESG indicator.
- `reject_candidate`: reject this candidate from future use.
- `needs_more_evidence`: request more source evidence.
- `defer_decision`: postpone the decision.

Reviewers should fill `reviewer` and `decision_reason` for accept/reject decisions. Corrections must preserve raw values and use the corrected fields only.
