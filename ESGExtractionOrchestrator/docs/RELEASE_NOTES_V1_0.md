# ESGExtractionOrchestrator v1.0 - Release Notes

First stable orchestrator release for running text, visual, and table candidate extraction from an existing `ESGInformationExtraction` output.

Outputs:

- `csv/`
- `visual/`
- `table/`
- `consolidated_candidates.csv`
- `consolidated_candidates.jsonl`
- consolidated audit files
- `full_extraction_report.md`

No source output is modified.
